# EV-Pulse Analytics

A premium dark-mode EV analytics dashboard built with React, TypeScript, Tailwind CSS, Recharts, and shadcn-style UI components.

## Features

- Executive EV adoption dashboard
- Charging infrastructure gap analysis
- County-level geospatial EV density view
- Price-to-range market insights
- Responsive sidebar navigation and executive presentation mode

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

## Tech stack

- React + TypeScript
- Vite + TanStack Start
- Tailwind CSS
- Recharts
- Lucide React
